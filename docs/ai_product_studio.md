# AI Product Studio Architecture & System Specification

SIH 26090: Artisan Market Linkage & Smart Seller Matching

## 1. Executive Summary
The **AI Product Studio** empowers Indian artisans to convert product photographs into structured, authentic catalogue listings. Built on a strict **AI Honesty Charter**, all vision model outputs are classified strictly as `AI_SUGGESTED` within an isolated staging layer. AI suggestions **NEVER** silently become verified product facts without explicit artisan review and confirmation.

---

## 2. Core Studio Workflow

```
[ Product Photograph ] (ProductMedia)
           │
           ▼
[ Multimodal Vision Understanding ] (Gemini 1.5/2.0 Flash / Mock)
           │
           ▼
[ Staged Attribute Extraction ] (AIProductAnalysis + AIProductSuggestion)
   - Title & Narrative
   - Raw Materials & Craft Technique
   - Color Palette & Motifs
   - Uncalibrated Confidence (Explicit Null)
   - Model & Prompt Provenance
           │
           ▼
[ Artisan Review & Adjudication ] (/artisan/products/[id]/ai-studio)
   ├── ACCEPT ──> Status: HUMAN_CONFIRMED
   ├── EDIT   ──> Status: HUMAN_CONFIRMED (Original AI suggestion preserved)
   └── REJECT ──> Status: REJECTED
           │
           ▼
[ Apply to Canonical Product Listing ] (apply_to_product = True)
   - Only confirmed attributes update canonical Product table
   - ai_metadata contract updated
   - If PUBLISHED, reverts to DRAFT for re-moderation
```

---

## 3. Key Architectural Principles

1. **Strict Staging Layer Isolation**:
   Running an AI analysis creates records exclusively in `ai_product_analyses` and `ai_product_suggestions`. The canonical `Product` row (`products`) remains 100% untouched until the artisan submits a confirmation request.
2. **Four Distinct Provenance States**:
   - `ARTISAN_PROVIDED`: Direct manual inputs from the artisan.
   - `SOURCE_BACKED`: Authoritative external facts (e.g. GI Registry data).
   - `AI_SUGGESTED`: Assistive predictions generated by AI models.
   - `HUMAN_CONFIRMED`: Suggestions explicitly reviewed, accepted, or edited by the artisan. (Note: `HUMAN_CONFIRMED` does **not** signify government verification or official certification).
3. **Zero Synthetic Confidence**:
   When vision models do not return mathematically calibrated probabilities, confidence is stored as `null`. Synthetic numbers (e.g. 95%, 98%) are never manufactured.
4. **Server-Side IDOR Defense**:
   All product, media, analysis, and confirmation operations verify product ownership server-side. Cross-artisan tampering returns HTTP 403 Forbidden.
5. **Re-Moderation Trigger**:
   If an artisan applies confirmed AI attributes to an already `PUBLISHED` product, the backend automatically transitions the listing back to `DRAFT` to prevent unreviewed changes from appearing publicly.
